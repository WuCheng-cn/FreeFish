# 功能与快捷键

## 默认全局快捷键

| 动作 | 快捷键 | 说明 |
|---|---|---|
| 显示 / 隐藏 | `Ctrl+Shift+H` | 老板键；隐藏后可再次按下唤回 |
| 上一页 / 下一页 | `Ctrl+Alt+←` / `Ctrl+Alt+→` | 在其他窗口聚焦时也有效 |
| 鼠标穿透 | `Ctrl+Shift+M` | 开启后用同一快捷键退出 |
| 切换置顶 | `Ctrl+Shift+T` | 控制窗口是否总在最前 |
| 单行模式 | `Ctrl+Shift+L` | 退出后恢复原窗口尺寸 |

窗口聚焦时可用 `←/→`、`Page Up/Page Down` 或 `Space` 翻页，`↑/↓` 滚动，`Esc` 隐藏，`Ctrl+F` 搜索。

所有全局快捷键都能在设置中重新录制。点击输入框后按新组合键，按 `Backspace` 可禁用，最后点击 **应用快捷键**。

## 阅读模式

- **单行模式：** 窗口缩为一行，方向键、滚轮或点击逐行移动。
- **鼠标穿透：** 隐藏界面，只保留文字，点击会落到下层窗口。
- **伪装模式：** 将正文显示成带行号的代码注释。
- **自动隐藏：** 无操作一段时间后隐藏，等待老板键唤回。

## 章节与搜索

FreeFish 默认识别“第 X 章 / 回 / 节 / 卷 / 部 / 篇 / 集 / 话”及序章、楔子、番外等标题。识别不准时，在设置里修改章节标题正则，再点击 **重新解析当前书**。

目录支持按章节名筛选。全文搜索结果可直接跳到原文并高亮定位。

## 常见问题

### 打开后乱码

少数冷门编码可能无法识别。请用记事本或 VS Code 将文件另存为 UTF-8。

### 全局快捷键无效

组合键可能已被其他软件占用。设置面板会显示注册失败的项目，换一个组合即可。安全软件拦截全局快捷键时也需要放行。

### 无法悬浮在游戏上

系统不允许普通窗口覆盖独占全屏应用。请把游戏改为无边框窗口模式。

### 窗口点不到

鼠标穿透模式处于开启状态。按默认的 `Ctrl+Shift+M` 退出。
