# Download FreeFish

Current installers are published on GitHub Releases. After installation, the application is named **SysNotes** as part of its disguise design.

[Download the latest release](https://github.com/WuCheng-cn/FreeFish/releases/latest){ .VPButton .brand }

## Choose a package

| System | Recommended file | Notes |
|---|---|---|
| Windows 10/11 | `.exe` | Preferred installer; `.msi` is also available |
| macOS | `.dmg` | Choose Apple Silicon or Intel to match your Mac |
| Linux | `.AppImage` | Runs directly; Debian/Ubuntu users can choose `.deb` |

::: warning Security prompts
The installers are not commercially code-signed. Windows SmartScreen or macOS Gatekeeper may show an unknown-developer warning. Only download files from this project's GitHub Releases.
:::

Older versions remain available under [all Releases](https://github.com/WuCheng-cn/FreeFish/releases).
