# 下载 FreeFish

最新安装包统一发布在 GitHub Releases。应用安装后的名称是 **SysNotes**，这是正常的伪装设计。

[前往最新版本下载](https://github.com/WuCheng-cn/FreeFish/releases/latest){ .VPButton .brand }

## 选择安装包

| 系统 | 推荐文件 | 说明 |
|---|---|---|
| Windows 10/11 | `.exe` | 首选安装程序；也可使用 `.msi` |
| macOS | `.dmg` | 根据 Mac 芯片选择 Apple Silicon 或 Intel 版本 |
| Linux | `.AppImage` | 直接运行；Debian/Ubuntu 也可选择 `.deb` |

::: warning 系统安全提示
当前安装包没有商业代码签名。Windows SmartScreen 或 macOS Gatekeeper 可能显示未知开发者提示，请仅从本项目的 GitHub Releases 下载。
:::

历史版本可在 [全部 Releases](https://github.com/WuCheng-cn/FreeFish/releases) 中找到。
